# 数码管驱动与按键消抖

::: warning 建设中
本文档仍处于草稿阶段，内容与实验要求可能调整，仅供参考。具体任务安排与验收要求以实验室确认发布的版本为准。
:::

## 实验任务

需要下板完成以下内容：

1. 完成七段数码管译码模块，固定显示数字 **6**。可选择其中一位数码管进行显示。
2. 动态数码管：在 **4 位数码管**上显示**学号后四位**。
3. 实现按键消抖模块：内部计数值在复位后为 `4'b0000`（十进制 0），每检测到一次**有效按键按下事件**加 1，序列为 0→1→2→3→4→0；计到 `4'b0100`（十进制 4）后，下一次有效按键回到 `4'b0000`。数码管显示当前计数值对应的十进制数字 0～4。

   这里的 `4'b0000` 是内部计数寄存器的值，不是数码管的物理段码，显示时仍需经过七段译码。

## 设计思路提示

任务 3 其实可以拆分为“按键消抖、按键事件产生、计数控制、数码管显示”等基础模块。按键消抖模块可以尝试使用状态机实现，再将各模块组合完成整体功能，注意层次化设计思想。

## 验证建议

建议在仿真或下板时至少验证以下行为：

- 按键抖动期间只产生一次计数事件。
- 长按按键不会持续计数，松开后再次按下才产生下一次计数事件。
- 复位后计数值回到 0，并从 0 重新开始计数。
