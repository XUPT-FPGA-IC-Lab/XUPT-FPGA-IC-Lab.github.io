# 16 位 LED 花型流水灯设计

::: warning 建设中

设计一个 16 位 LED 花型流水灯控制电路，通过 FPGA 开发板上的 16 个 LED 实现四种不同的流水灯显示效果，并按照指定顺序自动循环切换。

## 2.1 花型切换方式

1. **从左到右流水**：16 个 LED 每次点亮 1 个，从最左侧 LED 开始，依次向右移动，直到最右侧 LED。
2. **从右到左流水**：16 个 LED 每次点亮 1 个，从最右侧 LED 开始，依次向左移动，直到最左侧 LED。
3. **从中间向两边流水**：每次同时点亮左右对称的 2 个 LED，从中间的两个 LED 开始，逐步向两侧移动，直到最外侧的两个 LED。
4. **从两边向中间流水**：每次同时点亮左右对称的 2 个 LED，从最外侧的两个 LED 开始，逐步向中间移动，直到中间的两个 LED。

四种模式按照上述顺序依次执行，完成第四种模式后自动返回第一种模式，持续循环。

## 2.2 其他要求

1. LED 显示状态的切换间隔为 **1 秒**，每隔 1 秒更新一次点亮位置。
2. 使用开发板提供的系统时钟，通过计数器产生所需的定时控制信号。
3. 各模式之间自动切换，不需要人工干预。
4. 电路具有复位功能，复位后从第一种流水灯模式的初始状态开始运行。

## 2.3 提示

1. 根据开发板实际时钟频率设计计数器，保证流水灯切换时间符合要求。
2. 完成必要的功能仿真，验证四种流水灯模式正常运行与切换。
