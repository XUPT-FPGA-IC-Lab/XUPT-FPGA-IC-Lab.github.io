## 内容要求

在已完成的 UART 回环基础上，通过串口命令实时控制 FPGA 内部的功能模块。

你的任务是：为自己之前设计过的某个外设（或选择一个新的外设）增加一个串口命令接口，使其能够通过 PC 端的串口助手进行动态控制。你可以控制的模块包括但不限于之前完成的流水灯、售货机、篮球计分器等，也可以是任意一个具有可配置性的电路模块（比如一个支持多种算法切换的图像处理系统），根据个人感兴趣的方向选择。

我们会给大家较多的自由决策空间——你需要根据自己的应用场景，在命令格式、解析方式、是否使用 FIFO 等方面做出合理选择，并在验收时说明理由。

例如，控制 LED 的命令可以定义为：

| PC 发送内容   | 对应动作      | FPGA 回复      |
| --------- | --------- | ------------ |
| `LED ON`  | 点亮 LED    | `OK`         |
| `LED OFF` | 熄灭 LED    | `OK`         |
| `LED ?`   | 查询 LED 状态 | `ON` 或 `OFF` |

## 简易示例：呼吸灯控制器

如果你看完了前面的要求，还是不清楚怎么着手，可以结合本示例了解一下思路。

该设计的具体目标为：通过 PC 端发送串口指令，控制 FPGA 开发板上的呼吸灯模块，实现呼吸速度与花型（亮度变化模式）的动态调节。

### 1. 指令格式定义

我们将对接收到的 8 位数据进行自定义编码：高 2 位用于控制呼吸速度挡位，低 6 位用于控制花型模式。通过这种方式，一条单字节指令即可同时完成速度与花型的设定。

具体定义格式见下表：

| 数据位    | 功能   | 说明                      |
| ------ | ---- | ----------------------- |
| bit7~6 | 速度挡位 | 00：慢速，01：中速，10：快速，11：极速 |
| bit5~0 | 花型模式 | 000000~111111 共 64 种花型    |

例如，指令 `8'b00_111000` 表示：速度挡位为 00（慢速），花型模式为 `111000`（对应的 LED 灯效）。

### 2. 发送命令进行控制

在实际操作中，我们通常通过串口助手发送字符来控制 FPGA。例如，在串口助手中输入字符 `8`，其对应的 ASCII 码为 `8'b0011_1000`（即十六进制 `0x38`）。

<img src="../assets/uart/Pasted%20image%2020260329111441.png" alt="串口助手发送 ASCII 字符示例" width="554" loading="lazy" />

当 FPGA 接收到该字节后，我们需要对其进行解析：

- 高 2 位 `2'b00` 表示选择慢速挡位
- 低 6 位 `6'b111000` 用于控制 LED 花型

**注意**：串口助手可以切换显示模式。若以十六进制形式发送 `0x38`，则接收到的数据同样为 `8'b0011_1000`，解析逻辑不变。

<img src="../assets/uart/Pasted%20image%2020260329111523.png" alt="串口助手十六进制发送示例" width="544" loading="lazy" />

### 3. 指令解析模块设计参考

以下是一个简单的指令解码模块主要逻辑示例，用于从接收到的串口数据中提取速度挡位和花型信息，并产生对应的控制信号：

```verilog
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin
        speed_ctrl <= 2'b01;       // 默认中速
        pattern_ctrl <= 6'b000001; // 默认花型
    end else if (rx_valid) begin
        // 解析接收到的8位数据
        speed_ctrl <= rx_data[7:6];   // 高2位为速度挡位
        pattern_ctrl <= rx_data[5:0]; // 低6位为花型模式
    end
end

// 根据速度挡位计算分频计数值
parameter CLK_FREQ = 50_000_000; // 系统时钟频率
reg [31:0] pwm_period;

always @(*) begin
    case (speed_ctrl)
        2'b00: pwm_period = CLK_FREQ / 1;      // 1Hz 慢速
        2'b01: pwm_period = CLK_FREQ / 2;      // 2Hz 中速
        2'b10: pwm_period = CLK_FREQ / 4;      // 4Hz 快速
        2'b11: pwm_period = CLK_FREQ / 8;      // 8Hz 极速
        default: pwm_period = CLK_FREQ / 2;
    endcase
end
```
