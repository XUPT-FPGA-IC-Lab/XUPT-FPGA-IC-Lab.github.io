# 关于我们

我们是西安邮电大学 FPGA & IC 创新实验室，一个围绕 FPGA 与数字IC设计开展学习和实践的技术兴趣组织。

## 我们在做什么

从 Verilog、数字电路和仿真验证入手，通过实验任务与团队项目，逐步学习处理器、接口通信和嵌入式系统设计。我们每年参与相关学科竞赛，在具体问题中积累设计、调试与协作经验。

## 我们的学习方式

重视动手实践，也重视理解电路背后的原理。鼓励自主查阅资料、通过仿真验证想法，在遇到问题时交流思路，并将经验整理成可供后来者参考的文档。

## 关于本站

本站用于整理实验任务、学习资料和项目经验，方便成员查阅与交流。内容会持续修订，实验任务的具体安排以实验室通知为准。
