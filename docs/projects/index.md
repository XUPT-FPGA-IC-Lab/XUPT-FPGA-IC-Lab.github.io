# 研究与项目

实验室围绕 FPGA 与数字集成电路设计开展学习和项目实践，每年主要参加全国大学生集成电路创新创业大赛、全国大学生嵌入式芯片与系统设计竞赛，以及全国大学生计算机系统能力大赛 CPU 设计赛。我们希望通过具体赛题，把基础电路、模块设计、仿真验证与系统调试连接起来，逐步完成能够运行、测试和展示的作品。

## 主要参与赛事

### 全国大学生集成电路创新创业大赛

集创赛面向集成电路产业需求，由工业和信息化部人才交流中心主办，通过企业命题等形式考察设计实现、工程实践与团队协作能力，赛题覆盖芯片设计、芯片应用及产业链相关方向。赛事介绍见[官方章程](https://univ.ciciec.com/col.jsp?id=123)。

结合实验室的学习基础，可围绕数字逻辑、FPGA 应用、专用计算模块和系统集成等方向选题，在满足功能要求的基础上，进一步关注性能、资源占用和设计验证。

### 全国大学生嵌入式芯片与系统设计竞赛

这项竞赛聚焦嵌入式芯片、系统设计与可编程逻辑器件应用，强调自主设计、工程实现和团队合作，鼓励将芯片与软件结合起来解决实际问题。赛事介绍见[官方大赛说明](https://www.socchina.net/news?id=721e5e25543547759ccec506933c8978)。

可开展的项目包括外设控制、数据采集、图像处理和智能终端等。项目实践不仅涉及算法或单个模块，也需要完成接口通信、软件开发和整机联调，让各部分协同运行。

### 全国大学生计算机系统能力大赛 CPU 设计赛

CPU 设计赛又称“龙芯杯”，是全国大学生计算机系统能力大赛的组成部分，设有团体赛和个人赛，围绕处理器设计开展实践。赛事通知与技术方案可在[官方网站](https://www.nscscc.com/)查阅。

这一方向可从指令执行与流水线入手，逐步学习数据相关处理、访存系统、总线接口和处理器验证，再通过 FPGA 上板调试与性能分析，理解处理器如何与存储器、外设和软件共同构成完整系统。

## 从实验训练到项目实践

[实验任务](/labs/)中的状态机、UART、FIFO、AXI 握手与 VGA 显示，是进一步开展项目的基础。完成基础训练后，可以结合兴趣与当年赛题选择方向，通过分工协作推进设计、验证和系统集成，并整理代码、测试结果与演示材料，积累可复用的工程经验。

各赛事的具体赛题、参赛条件与时间安排，以当年官方通知为准。
